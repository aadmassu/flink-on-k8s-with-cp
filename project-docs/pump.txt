Environment reminders:
- These are OpenShift core-zone internal URLs (apps.dv-p.ocp.fcbint.net wildcard → 10.7.72.209).
- Only reachable from FCB corporate network / VPN.
- If Zscaler is dropping them, they'd typically show as timeout or ERR_TIMED_OUT, not ERR_CONNECTION_CLOSED. But worth checking network posture.
- All five ingresses use route.openshift.io/termination: reencrypt.
- All backend TLS certs are Keyfactor-issued via cert-manager (kafka-tls, controlcenter-tls, etc.), signed by FCB internal CA.

Steps to run in Chrome:

If curl is available on your laptop, this one-liner covers everything:
  for u in \
    https://controlcenter.apps.dv-p.ocp.fcbint.net/ \
    https://schemaregistry.apps.dv-p.ocp.fcbint.net/subjects \
    https://kafka-mds.apps.dv-p.ocp.fcbint.net/kafka/v3/clusters \
    https://kafkarest.apps.dv-p.ocp.fcbint.net/v3/clusters \
    https://connect.apps.dv-p.ocp.fcbint.net/connectors; do
    echo "--- $u ---"
    curl -sk --max-time 8 -o /dev/null -w "HTTP %{http_code} (%{size_download}B in %{time_total}s)\n" "$u"
  done
