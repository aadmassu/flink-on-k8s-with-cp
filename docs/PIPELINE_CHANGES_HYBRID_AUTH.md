# Pipeline Changes — Hybrid Authentication Refactor

## Summary

The `confluent-platform.yaml` pipeline was **already updated** during DEV hybrid auth implementation. No additional changes are required.

The pipeline correctly:

1. ✅ Requires **only one** SASL/PLAIN credential per environment: `<env>-sasl-plain-admin-pwd`
2. ✅ Creates `sasl-plain-internal` Secret with five keys (all containing the same `admin` password)
3. ✅ No longer requires or consumes five legacy component-specific PLAIN passwords
4. ✅ Passes the single credential through the template to generate the expected Secret structure

## Deployment Order

When deploying to a new environment:

1. **Ensure variable group is populated:**
   ```bash
   # Run diagnostics pipeline to confirm variables are set
   ```

2. **Create prerequisites:**
   ```
   Pipeline: confluent-platform
   Parameters:
     - environment: <target-env>
     - action: create-prereqs
     - bypassEsoForSecrets: none (default)
   ```

3. **Verify Secrets:**
   ```bash
   oc -n dah-flink-<env> get secret sasl-plain-internal -o jsonpath='{.data}' | jq 'keys'
   ```

4. **Deploy KRaft + Kafka:**
   ```
   Pipeline: confluent-platform
   Parameters:
     - environment: <target-env>
     - action: install-or-update
     - applyAll: true (or select KRaft + Kafka individually)
   ```

5. **Wait for readiness (readiness gates disabled):**
   - Monitor manually: `oc -n dah-flink-<env> get kafka,kraftcontroller -w`

6. **Deploy managed components:**
   - Schema Registry, Connect, REST Proxy, Control Center

## Validation Checklist
